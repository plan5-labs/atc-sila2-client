# atc-sila2-client

## Installation

This package is not published on PyPI. Install it from the GitHub repository using [uv](https://docs.astral.sh/uv/).

**As a dependency of your project** (from your project's root directory):

```bash
uv add git+https://github.com/plan5-labs/atc-sila2-client.git
```

**Into an existing environment** (like `pip install`):

```bash
uv pip install git+https://github.com/plan5-labs/atc-sila2-client.git
```

**For development** (clone and install in editable mode):

```bash
git clone https://github.com/plan5-labs/atc-sila2-client.git
cd atc-sila2-client
uv sync
```

Requires Python 3.10 or later.
